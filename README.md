# Chatbot CET 115

Repositorio del proyecto de bot de Telegram (Laboratorios 5a y 5b).

## Cómo trabajar

1. Crea tu rama: `git switch -c alumno/<TU_CARNET>` (carnet en MAYUSCULAS).
2. Sube tu rama: `git push -u origin alumno/<TU_CARNET>`.
3. Abre un Merge Request de tu rama hacia `main`, en estado Draft. No lo fusiones.
4. Todo tu trabajo de 5a y 5b va en esa misma rama / ese mismo MR.

## Reglas

- El token del bot va en `.env` (copia de `.env.example`). `.env` NUNCA se sube.
- Commits descriptivos y frecuentes: es lo que se califica.
- No toques la rama de otro compañero.
