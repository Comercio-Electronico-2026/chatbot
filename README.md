# Chatbot CET 115

Repositorio del proyecto de bot de Telegram (Laboratorios 5a y 5b).

## Cómo trabajar

1. Crea tu rama: `git switch -c alumno/<TU_CARNET>` (carnet en MAYUSCULAS).
2. El documento de diseño (Lab 5a) va en `docs/diseno-conversacional.md`; el
   código del bot (Lab 5b) va en `src/`.
3. Sube tu rama: `git push -u origin alumno/<TU_CARNET>`.
4. Abre un Pull Request de tu rama hacia `main`, en estado Draft. No lo fusiones.
5. Todo tu trabajo de 5a y 5b va en esa misma rama / ese mismo PR. Pasa el enlace
   del PR al docente.

Pasos detallados y la tabla de rama por alumno: `GITHUB_EVIDENCIAS.md`.

## Reglas

- El token del bot va en `.env` (copia de `.env.example`). `.env` NUNCA se sube.
- Commits descriptivos y frecuentes: es lo que se califica.
- No toques la rama de otro compañero ni la rama `main`.
